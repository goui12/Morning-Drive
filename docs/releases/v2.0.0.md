# Morning Drive 2.0.0

[Download Morning_Drive.apk](https://github.com/goui12/Morning-Drive/releases/latest/download/Morning_Drive.apk)

## What's new

- Save named locations and see the address below each name.
- Assign different destinations to Monday through Sunday; the week repeats until changed.
- Use one usual departure time with optional times for individual days.
- Assign one location to several selected days or every enabled day; copy a day's plan.
- Add, edit, test, and remove saved locations; no five-location limit.
- Skip one departure, undo a skip, or pause all automation without losing the plan.
- See the next departure and unsaved changes; save planning edits before changing automation.
- Follow the one-time setup buttons and use Check for updates for the latest APK.
- Keep version 1's saved address, weekdays, time, and signing identity during the update.

## Install

Open the downloaded APK and tap Install. If prompted, allow installation from the browser/file manager that opened it. On Samsung, if Auto Blocker prevents installation, temporarily turn it off under Settings → Security and privacy → Auto Blocker, install, then turn it back on. Open Morning Drive and follow its setup buttons. Google Maps should already be installed and configured.

This is a personal APK release, not a Google Play listing. No GitHub account is needed to download it.

## Behavior

A locked phone keeps today's departure pending until unlock; the pending trip expires at midnight. At most one automatic handoff is sent per local day. Saving/enabling applies to future departures. Maps handles routing and guidance. The app cannot bypass the lock screen or verify that Maps entered guidance after accepting the request.
